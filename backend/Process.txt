1. What are ES Modules and CommonJS?
=> ES Modules and CommonJS are two different module systems in JavaScript. They define how we split code into multiple files and how we import and export code between those files.

    eg;
    1. ES: /modles/product.js, CommonJS: /models/product
    2. import from, require
    3. export edfault, module.export
